\section*{Declaration of AI-based Tools}

In accordance with the guidelines of the University of Stuttgart, I hereby declare the use of AI-supported tools within the scope of this thesis. I explicitly state that the use of these tools was strictly limited to linguistic refinement, drafting assistance, and technical implementation. 
\textbf{All scientific questions, the argumentation structure, the methodological planning, and the core ideas were developed independently and without generative influence from AI.}

\subsection*{Linguistic Refinement and Drafting}
The following tools were used to translate my concepts into an academic writing style and for linguistic smoothing and correction:
\begin{itemize}
    \item \textbf{DeepL Write} (Source: \url{https://www.deepl.com/write}) -- Primary tool for linguistic corrections.
    \item \textbf{ChatGPT-4o}  (Source: \url{https://openai.com}) -- Drafting assistance.
    \item \textbf{Gemini 3 Pro} (Source: \url{https://gemini.google.com}) -- Drafting assistance.
    \item \textbf{NotebookLM} (Source: \url{https://notebooklm.google.com}) -- Drafting assistance.
\end{itemize}
These models were used to articulate my own drafts and thoughts more precisely. Control over the content and the scientific validity remained with me at all times.

\subsection*{Programming and Technical Implementation}
\textbf{GitHub Copilot} (Source: \url{https://github.com/features/copilot}) was used as an assistive tool for programming, debugging, and syntax optimization. The tool served to implement the program logic defined by me more efficiently into code. The algorithms and the software architecture were determined by me, and the results were verified independently.
